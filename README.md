## 왜 만들었나

macOS에서 모니터를 여러 대 쓰면 Dock이 한자리에 가만히 있지 않습니다. 아무 모니터에서나 포인터를 화면 하단으로 꾹 밀면 Dock이 그 모니터로 따라와버립니다. 잠깐 마우스를 내렸을 뿐인데 Dock이 옆 모니터로 이사를 가 있고, 다시 데려오려면 또 하단을 꾹 눌러야 합니다. 산책 나갈 때마다 주인을 앞질러 뛰어가는 강아지 같달까요.

Apple이 준 선택지는 둘뿐입니다. "디스플레이별 공간 사용"을 끄면 Dock은 고정되지만 Space 전환 시 모든 모니터가 한꺼번에 넘어가는 더 큰 불편이 생깁니다. 켜두면 Space는 독립적이지만 Dock이 떠돌아다닙니다. 둘 다 갖는 방법이 없어서 직접 만들었습니다.

GoodDock은 Dock에게 "기다려"를 가르칩니다. 지정한 모니터에서만 Dock이 나오고, 다른 모니터에서는 아무리 하단을 밀어도 넘어가지 않습니다. Space는 원래대로 모니터별로 독립적으로 동작합니다.

## 어떻게 동작하나

macOS는 Dock을 특정 디스플레이에 고정하는 API를 제공하지 않습니다. 그래서 GoodDock은 Dock을 직접 건드리는 대신, Dock이 다른 모니터로 넘어가는 조건 자체를 없앱니다.

Dock 이동의 트리거는 "화면 하단 끝에 눌린 포인터를 한 번 더 아래로 미는" 동작입니다. GoodDock은 마우스 이벤트를 감시하다가, 고정 화면이 아닌 모니터의 맨 아래 가장자리에서 이 동작이 감지되는 순간 포인터를 몇 픽셀 위로 되돌립니다. 포인터가 바닥에 붙어 있을 수 없으니 Dock을 부르는 조건이 성립하지 않습니다.

아래에 다른 모니터가 이어져 있는 가장자리는 자동으로 제외하므로, 모니터 사이의 포인터 이동은 방해받지 않습니다.

## 기능

- 메뉴 막대의 강아지 아이콘으로 상주하며, Dock 아이콘은 차지하지 않습니다
- 실제 모니터 배치를 그대로 축소한 미니맵에서 클릭으로 고정 화면을 선택합니다
- 모니터 연결이나 배치가 바뀌면 자동으로 다시 인식합니다
- 메뉴에서 작동 상태와 Dock 이동 차단 횟수를 확인할 수 있습니다
- 로그인 시 자동 실행을 토글할 수 있습니다
- 언제든 "고정 안 함"으로 원래 동작으로 되돌릴 수 있습니다

## 설치

요구 사항은 macOS 13 이상입니다.

[Releases](https://github.com/Seo-yul/GoodDock/releases/latest)에서 DMG를 받아 열고, GoodDock을 응용 프로그램 폴더로 끌어놓으세요.

이 앱은 Apple 개발자 인증서로 서명되어 있지 않아서 처음 열 때 Gatekeeper가 막습니다. **앱을 우클릭한 뒤 "열기"를 선택**하고 한 번 더 "열기"를 누르면 이후로는 그냥 실행됩니다. 그래도 열리지 않으면 아래 명령으로 격리 속성을 지우면 됩니다.

```bash
xattr -dr com.apple.quarantine /Applications/GoodDock.app
```

### 첫 실행 설정

첫 실행 시 손쉬운 사용(Accessibility) 권한을 요청합니다. 시스템 설정 > 개인정보 보호 및 보안 > 손쉬운 사용에서 GoodDock을 허용해주세요. 허용하면 앱이 자동으로 감지해서 바로 동작합니다.

그다음 메뉴 막대의 강아지를 눌러 Dock을 앉혀둘 모니터를 클릭하면 끝입니다. 메뉴 맨 위가 "작동 중"으로 보이면 정상입니다.

> **주의:** "디스플레이별 공간 사용"(시스템 설정 > 데스크탑 및 Dock > Mission Control)은 켜진 상태여야 합니다. 이 설정이 꺼져 있으면 macOS가 알아서 Dock을 고정하는 대신 Space가 전 모니터에서 묶여버리는데, 그 불편을 피하는 것이 이 앱의 존재 이유입니다.

## 제거

GoodDock을 종료한 뒤 `/Applications/GoodDock.app`을 휴지통에 넣으면 됩니다. 설정까지 완전히 지우시려면 터미널에서 아래를 실행하세요.

```bash
defaults delete local.gooddock
tccutil reset Accessibility local.gooddock
```

## 알아둘 점

- 고정하지 않은 모니터에서는 화면 맨 아래 2픽셀 지점에 포인터를 계속 밀어붙이는 동작이 살짝 제한됩니다. Dock을 막는 원리상 필요한 비용이고, 일반적인 클릭에는 영향이 없습니다.
- 앱을 종료하면 모든 동작이 즉시 원래대로 돌아갑니다. 시스템 설정을 건드리지 않습니다.
- 저장하는 값은 고정 화면의 디스플레이 UUID 하나뿐이고, `~/Library/Preferences/local.gooddock.plist`에 들어갑니다.
- 네트워크 통신은 전혀 하지 않습니다.

## 이름에 대하여

Dock이 말을 안 듣고 돌아다니길래 훈련을 시켰습니다. 이제 지정한 자리에 얌전히 앉아 기다립니다. 착한 Dock, GoodDock입니다.
