GoodDock

앉아. 기다려. 착하지.

멀티 모니터에서 이리저리 떠돌아다니는 macOS Dock을, 원하는 화면 하나에 얌전히 앉혀둡니다.

내려받기 GitHub

무료 · macOS 13 이상

이런 적 있으신가요

모니터를 여러 대 쓰다 보면 Dock이 한자리에 가만히 있지 않습니다. 아무 모니터에서나 포인터를 화면 아래로 꾹 밀면 Dock이 그쪽으로 따라와버립니다. 잠깐 마우스를 내렸을 뿐인데 Dock이 옆 모니터로 이사를 가 있고, 다시 데려오려면 또 하단을 눌러야 합니다.

Apple이 준 선택지는 둘뿐이고 어느 쪽도 답이 아닙니다. "디스플레이별 공간 사용"을 끄면 Dock은 고정되지만, Space를 전환할 때 모든 모니터가 한꺼번에 넘어가는 더 큰 불편이 생깁니다. 켜두면 Space는 독립적이지만 Dock이 떠돌아다닙니다.

GoodDock은 그 사이의 빈칸을 채웁니다. Space는 모니터별로 그대로 두고, Dock만 지정한 화면에 붙잡아 둡니다.

기능

화면을 그림으로 선택

실제 모니터 배치를 축소한 지도에서 클릭 한 번으로 고정할 화면을 고릅니다.

배치 변경 자동 인식

모니터를 새로 연결하거나 분리하거나 위치를 바꿔도 알아서 인식합니다.

가볍게 상주

메뉴 막대 아이콘 하나로 동작합니다. Dock 자리를 차지하지 않습니다.

언제든 되돌리기

"고정 안 함"을 고르거나 앱을 종료하면 즉시 원래 동작으로 돌아갑니다.

로그인 시 자동 실행

한 번 켜두면 다음 로그인부터 알아서 대기합니다.

네트워크 사용 없음

어떤 데이터도 밖으로 보내지 않습니다. 저장하는 값은 선택한 화면 하나뿐입니다.

어떻게 동작하나요

macOS에는 Dock을 특정 화면에 고정하는 기능이 없습니다. 그래서 GoodDock은 Dock을 직접 옮기는 대신, Dock이 다른 모니터로 넘어가는 조건 자체를 없앱니다.

Dock을 부르는 동작은 화면 맨 아래에 닿은 포인터를 한 번 더 아래로 미는 것입니다. GoodDock은 고정하지 않은 모니터에서 이 동작이 감지되면 포인터를 살짝 위로 되돌립니다. 포인터가 바닥에 붙어 있을 수 없으니 Dock이 불려 나올 일도 없습니다.

아래쪽에 다른 모니터가 이어져 있는 가장자리는 자동으로 제외하므로, 모니터 사이를 오가는 포인터 이동은 전혀 방해받지 않습니다.

설치

  1. Releases에서 DMG를 받아 엽니다.
  2. GoodDock을 응용 프로그램 폴더로 끌어놓습니다.
  3. 처음 열 때는 앱을 우클릭한 뒤 "열기"를 선택하고, 한 번 더 "열기"를 누릅니다.
  4. 손쉬운 사용 권한을 허용합니다. (시스템 설정 > 개인정보 보호 및 보안 > 손쉬운 사용)
  5. 메뉴 막대의 강아지를 눌러 Dock을 앉혀둘 모니터를 클릭합니다.

3번 과정이 필요한 이유는 이 앱이 Apple 개발자 인증서로 서명되어 있지 않기 때문입니다. 그래도 열리지 않으면 터미널에서 아래를 실행하세요.

xattr -dr com.apple.quarantine /Applications/GoodDock.app

주의: "디스플레이별 공간 사용"(시스템 설정 > 데스크탑 및 Dock > Mission Control)은 켜져 있어야 합니다. 이 설정을 끄면 모든 모니터가 같은 Space로 묶이는데, 바로 그 불편을 피하려고 만든 앱입니다.

자주 묻는 질문

왜 손쉬운 사용 권한이 필요한가요?
마우스가 화면 아래 가장자리에 닿는 순간을 알아채려면 시스템의 마우스 이벤트를 지켜봐야 하고, macOS는 이 권한을 손쉬운 사용으로 관리합니다. GoodDock은 커서 위치만 보며 키 입력은 읽지 않습니다.

느려지지 않나요?
마우스 이벤트 하나를 처리하는 데 약 11나노초가 걸립니다. 마우스를 아주 빠르게 움직여도 CPU 코어 하나의 0.001% 수준입니다.

제거하려면요?
앱을 종료하고 휴지통에 넣으면 됩니다. 시스템 설정을 바꾸지 않으므로 Dock은 즉시 원래대로 돌아갑니다.
